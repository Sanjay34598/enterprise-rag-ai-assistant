# Enterprise RAG AI Assistant

A production-ready Retrieval-Augmented Generation (RAG) platform that enables organizations to securely interact with their documents using Large Language Models.

## Features

- Secure Authentication
- PDF Upload
- Document Processing
- AI Chat
- Source Citations
- Chat History
- Multi-user Support
- Admin Dashboard
- Docker Deployment
