# Architecture Documentation

This directory contains system architecture specifications, design blueprints, database schemas, API contracts, and engineering standards for the Enterprise RAG AI Assistant.

## Specifications Index
- [System Design](system-design.md): High-level system topology, Clean Architecture rules, and core component responsibilities.
- [Database Schema](database-schema.md): PostgreSQL relational entities and PGVector embedding layout.
- [API Design](api-design.md): RESTful route standards, SSE streaming specs, and error handling model.
- [Sequence Diagrams](sequence-diagrams.md): Mermaid workflow diagrams for Authentication, Ingestion, and RAG execution.
- [Tech Stack Evaluation](tech-stack.md): Architectural decisions and rationale for chosen frameworks and libraries.
- [Coding Standards](coding-standards.md): Code style, static typing guidelines, and SOLID compliance rules.
