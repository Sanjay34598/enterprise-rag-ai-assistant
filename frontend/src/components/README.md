# UI Components Library (`src/components/`)

Organized using atomic design principles:
- `ui/`: Design primitives (Buttons, Inputs, Modals).
- `layout/`: App Shell, Headers, Sidebars.
- `chat/`: Chat message list, prompt boxes, citations preview drawers.
- `documents/`: File upload dropzones, ingestion progress monitors.
- `common/`: Cross-cutting UI feedback components (Loading spinners, Error boundaries).
